# FinesseBot - Discord Role Assignment & Commissions Handler Bot

A soft-coded, modular Discord bot that automatically tracks member activity and assigns roles based on:
1. **Message Count** - Number of messages sent in the server.
2. **Server Tenure** - Number of days spent in the server.
3. **Combined Criteria** - Requiring both message threshold and tenure threshold.

---

## Features

- Completely soft-coded, works on a simple config.
- Adds 2 parametres for role assignment: **Time** and **Message Count**
- Includes a commissions handler connected to my portfolio(https://almanax21.com) to directly send information to my discord
- Automatically generates a key that allows users to join and claim their tickets.
